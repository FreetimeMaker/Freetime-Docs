# Getting Started

This is the archived v1 snapshot of Freetime Docs, the technical documentation for Freetime Maker projects.

## Choose a project

Start from the [Projects overview](../projects/) and select the application or service you are working with.

## Documentation structure

Projects use the same model where applicable: Getting Started, User Guide/Features, Configuration, Architecture, Development, API/Backend, Troubleshooting and Releases.

## Documentation versions

Docs versions are independent from application releases. Use docmd's built-in version selector to switch between the current documentation and archived snapshots. Links within this snapshot open the archived project pages.
