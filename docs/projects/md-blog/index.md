# MD-Blog

A static Markdown blog with API-backed content and bundled local fallbacks.

**Technologies:** Node.js build tools, Markdown, GitHub Pages

[Get started](./getting-started.md) · [Source code](https://github.com/FreetimeMaker/MD-Blog)

The inspected package version is **2.0.0**, not a verified published release.

## How it works

1. **Build:** Render `public/md/index.md` and generate post shells in `dist` from API discovery plus local Markdown routes.
2. **Host:** Serve static files with GitHub Pages; Node is only needed for build and local preview.
3. **Read:** Browser JavaScript fetches posts/categories from [All API](../all-api/index.md), falling back per failed request to bundled `public/blogs` content.

The homepage is pre-rendered. Blog posts, titles and category filters render in the browser and require JavaScript; generated post files are shells, not snapshots of the API Markdown.

## Features present in source

- Marked rendering with DOMPurify sanitization for blog Markdown
- title-based canonical paths with API-slug and legacy URL compatibility
- newest-first publication-date sorting
- case-insensitive category filters requiring every selected category
- recursive local Markdown fallback bundled at build time
- English Discord-style timestamps, light/dark styling and persisted theme choice
- static local preview and GitHub Pages build/test/deploy workflow

## Content and configuration

Edit `public/md/index.md` for the homepage and `public/blogs/**/*.md` for local fallbacks. Rebuild after local changes. Local posts are not merged into a successful API listing.

The API is hardcoded as `https://api.free-time.me/v2` in `scripts/post-pages.js` and `public/scripts/blog.js`; `ALL_API_URL` is no longer used. Browser requests are credential-free and depend on backend CORS. No secret belongs in the bundle.

The site assumes the custom-domain root `https://blog.free-time.me`. New posts can render through `404.html` but keep HTTP 404 until their paths are generated by another build. The former Node handlers and Vercel configuration were removed.
