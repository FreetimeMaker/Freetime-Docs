# Multi AI Chat

Multi AI Chat is a Freetime Maker project for using multiple AI providers from one integration.

**Repository:** [FreetimeMaker/Multi-AI-Chat](https://github.com/FreetimeMaker/Multi-AI-Chat)

## Development focus

The project supports configurable AI providers and models and is designed to keep provider-specific settings separate from the user-facing chat workflow.

Provider API keys are configuration secrets and must never be committed to the repository.
