# Projects

Freetime Docs contains documentation for the following Freetime Maker projects. Setup, versions and features are checked against the available source repositories; a local build version does not necessarily identify the latest published release.

## Choose a project

### [Freetime Core](./freetime-core/index.md)

Shared building blocks for expressive Android applications.

**Technologies:** Android, Kotlin, Library

[Get started](./freetime-core/getting-started.md) · [Source code](https://github.com/FreetimeMaker/Freetime-Core)

### [GeoWeather](./geoweather/index.md)

Forecasts, weather alerts and home-screen widgets for Android.

**Technologies:** Android, Compose, Weather

[Get started](./geoweather/getting-started.md) · [Source code](https://github.com/FreetimeMaker/GeoWeather)

### [Luma Store](./luma-store/index.md)

**Technologies:** Android, Web, App store

[Get started](./luma-store/getting-started.md) · [Source code](https://github.com/FreetimeMaker/Luma-Store-Android)

### [SuperSMP Companion](./supersmp-companion/index.md)

An unofficial Android companion for the SuperSMP community.

**Technologies:** Android, Community, Companion

[Get started](./supersmp-companion/getting-started.md) · [Source code](https://github.com/FreetimeMaker/SuperSMP-Companion-App)

**Technologies:** Node.js, Express, Backend

[Get started](./all-api/getting-started.md) · [Source code](https://github.com/FreetimeMaker/All-API-Node)

**Technologies:** Node.js, Markdown, Web

[Get started](./md-blog/getting-started.md) · [Source code](https://github.com/FreetimeMaker/MD-Blog)

Multiple AI providers in one JetBrains IDE workflow.

**Technologies:** JetBrains, Kotlin, Plugin

[Get started](./multi-ai-chat/getting-started.md) · [Source code](https://github.com/FreetimeMaker/Multi-AI-Chat)

## Not sure where to start?

- **Building an Android app?** Start with [Freetime Core](./freetime-core/index.md).
- **Connecting a backend or blog?** Explore [All API](./all-api/index.md) and [MD-Blog](./md-blog/index.md).
- **Publishing an Android app?** Read the [Luma Store submission guide](./luma-store/submissions.md).
- **Looking for installation or setup?** Open a project and choose its **Get started** action.
