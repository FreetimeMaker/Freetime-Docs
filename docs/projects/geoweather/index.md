# GeoWeather

GeoWeather is a modern Android weather application inspired by MeteoSwiss.

**App repository:** [FreetimeMaker/GeoWeather](https://github.com/FreetimeMaker/GeoWeather)  
**Website repository:** [FreetimeMaker/GeoWeather-Website](https://github.com/FreetimeMaker/GeoWeather-Website)

## Features

GeoWeather supports multiple cities, 16-day and hourly forecasts, configurable units, notifications, localization, Material You dynamic colors and an integrated changelog.

## Android stack

- Kotlin
- Jetpack Compose
- Material 3 / Material You
- Room
- Retrofit and OkHttp
- Coil
- WorkManager

## Backend

GeoWeather backend functionality is part of [All API](/projects/all-api/), including subscription plans, code redemption and current-subscription lookup.

## Distribution

The Android app is distributed through GitHub releases and F-Droid-compatible channels. Translation resources are maintained separately from the application code.
