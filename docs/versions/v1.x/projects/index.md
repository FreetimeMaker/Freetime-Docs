# Projects

Freetime Docs contains the documentation for actively maintained Freetime Maker projects.

## Applications

- [GeoWeather](./geoweather/) — Android weather application.
- [Luma Store](./luma-store/) — App store ecosystem for Android, Linux and the web.
- [SuperSMP Companion](./supersmp-companion/) — Android companion app for SuperSMP.
- [Freetime News](./freetime-news/) — Android news reader for Freetime content.
- [Multi AI Chat](./multi-ai-chat/) — Multi-provider AI chat integration.

## Services and web projects

- [All API](./all-api/) — Central backend for Freetime Maker services.
- [MD-Blog](./md-blog/) — Markdown-powered blog platform.
